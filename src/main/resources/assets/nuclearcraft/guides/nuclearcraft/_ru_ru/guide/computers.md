# Управление компьютером

Большинством мультиблоков NuclearCraft можно управлять и считывать их данные через
**ComputerCraft** (периферия) или **OpenComputers v2** (устройства). Обе API зеркальны: имена
методов и возвращаемые значения совпадают, поэтому скрипт переносится между ними изменением лишь
способа получения дескриптора.

Эти страницы охватывают семейство ускорителей. Полный список по всем блокам - реакторы, турбины,
процессоры, кугельблиц - см. в справочнике `COMPUTERS.md`, поставляемом с модом.

## Порты луча

Ускоритель, кольцевой ускоритель, камеры частиц и разветвитель луча предоставляют два метода
для управления портами луча во время работы:

- `getBeamPortsInfo()` → list | nil — по одной записи на каждый порт луча, отсортированы по позиции.
  Каждая запись - таблица: `id` (int), `x` / `y` / `z` (int), `mode` (`"input"`, `"output"` или
  `"disabled"`) и `particle` (таблица с `energy` / `focus` / `amount` / `particle`, либо nil).
- `setBeamPortMode(id, mode)` → boolean — задать порту `id` режим `"input"`, `"output"` или
  `"disabled"` (без учёта регистра). Возвращает `false`, если мультиблок не собран или аргументы
  неверны.

Оба выполняются в серверном потоке (`mainThread = true` в ComputerCraft, `synchronize = true` в
OpenComputers), поэтому вызывайте их экономно.
