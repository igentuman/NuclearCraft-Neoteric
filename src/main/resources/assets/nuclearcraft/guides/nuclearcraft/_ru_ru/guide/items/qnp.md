# QNP

## QNP

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="qnp" />
</Column>

**QNP** - продвинутый мультиинструмент. Добывает любой блок и имеет несколько режимов: 3x3, 3x3x3, 5x5, жила и одиночный блок. Требует энергии.
