# Инженерный верстак

<Column alignItems="center" fullWidth={true}>
  <BlockImage id="engineers_crafting_table" />
</Column>

Автокрафтовый терминал с питанием. Загрузите в него контейнеры-хранилища и подведите энергию — он собирает по спецификации, по одной операции за тик.

## Запасы

У верстака **6** слотов под **Контейнеры-хранилища**. Их суммарное содержимое становится запасом для крафта, объединённым по всем вставленным контейнерам. Пополняйте или меняйте контейнеры, чтобы полки не пустели.

## Кодировщик схем

Откройте **Кодировщик схем**, чтобы записать рецепт на **Пустую схему**. Каждая схема связывает свои ингредиенты с результатом. Одновременно загружается до **36** схем, и решатель связывает их, чтобы автоматически крафтить промежуточные детали.

## Энергия

Работает на FE:

- Буфер держит **10 000 FE**, принимает до **1 000 FE/т**.
- В простое тратит **100 FE/т**.
- Каждая операция крафта стоит **200 FE**.

Без энергии линия встаёт до восстановления питания.

## Автоматизация

Верстак предоставляет периферию для **ComputerCraft** и **OpenComputers 2**. Запрашивайте запасы и записанные схемы, затем ставьте крафт в очередь программно. Список методов — в разделе «Компьютеры».
