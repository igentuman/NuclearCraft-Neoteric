# Универсальная труба

<Row>
  <BlockImage id="pipe" />
  <BlockImage id="pipe_connector" />
</Row>

**Универсальная труба** — единый канал, одновременно передающий предметы, жидкости и энергию по одной сети. Трубы лишь протягивают сеть; с соседним блоком взаимодействует **Коннектор трубы**.

## Сети

Соединённые трубы объединяются в одну сеть. Все коннекторы на ней делят общие предметы, жидкости и энергию. Приставьте коннектор к любому инвентарю, баку или машине, чтобы связать их, затем откройте его GUI для настройки.

## Каналы передачи

Новый коннектор не передаёт ничего. Отметьте **Предметы**, **Жидкости** или **Энергию**, чтобы разрешить каждый канал отдельно — все три неактивны до разрешения.

## Направление

Переключайте направление передачи:

- **Отключено** — передачи нет.
- **Извлечение** — забирать из блока.
- **Ввод** — подавать в блок.
- **Авто** — блок решает сам.

## Редстоун

Задайте **Редстоун: игнор** для постоянной работы или **Редстоун: требуется** для работы только при наличии сигнала.
