# Паксели

<Row>
  <ItemImage id="spaxelhoe_thorium" />
  <ItemImage id="spaxelhoe_tough" />
</Row>

**Паксель** сочетает кирку, топор, лопату, меч и мотыгу в одном надёжном инструменте. **Ториевый паксель** - средний уровень; **Усиленный паксель** - вершина: выше урон, значительно выше прочность. Полевые ремонтные бригады носят по одному; полевые ремонтные бригады лёгкого вооружения не признают.
