# Имплозионное устройство Pu-239

<Column alignItems="center" fullWidth={true}>
  <BlockImage id="pu_239_bomb" />
</Column>

**Имплозионное устройство Pu-239** - имплозионная сборка с плутониевой сердцевиной, образец Mk-VII. Взводится подачей редстоуна, отсчёт 3 с, затем инициация. Полевая мощность. Рекомендуемая минимальная дистанция: следующий биом. (Fat Man позавидовал бы такой логике запуска.)
