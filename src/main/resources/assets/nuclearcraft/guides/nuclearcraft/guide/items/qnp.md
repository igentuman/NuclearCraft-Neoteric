# QNP

## QNP

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="qnp" />
</Column>

The **QNP** is an advanced multitool. It can mine any block and has several modes: 3x3, 3x3x3, 5x5, vein, and single block. Requires energy.
