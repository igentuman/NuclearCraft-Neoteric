# Rad-X

## Rad-X

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="rad_x" />
</Column>

**Rad-X** provides its user with a set amount of radiation resistance for a set amount of time. Although the effect can be stacked, higher levels of resistance wear off more quickly than lower ones.
