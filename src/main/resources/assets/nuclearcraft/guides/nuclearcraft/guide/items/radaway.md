# Radaway

## Radaway

<Row>
  <ItemImage id="radaway" />
  <ItemImage id="radaway_slow" />
</Row>

**RadAway**, and its slower counterpart **Slow-Acting RadAway**, remove rads from the user at a set rate. Standard RadAway acts faster than the slow-acting variant, but does not last as long.
