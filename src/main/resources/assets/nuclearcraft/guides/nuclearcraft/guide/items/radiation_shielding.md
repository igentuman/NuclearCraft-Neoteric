# Radiation Shielding

## Radiation Shielding

<Row>
  <ItemImage id="light" />
  <ItemImage id="medium" />
  <ItemImage id="heavy" />
  <ItemImage id="dps" />
</Row>

**Radiation Shielding** can be added to armour to give it radiation resistance. The amount of radiation resistance added to the armor depends on the type of shielding used. When adding shielding to armour, the radiation resistance from each piece stacks.
