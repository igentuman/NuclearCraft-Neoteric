# Pu-239 Implosion Device

<Column alignItems="center" fullWidth={true}>
  <BlockImage id="pu_239_bomb" />
</Column>

The **Pu-239 Implosion Device** is a plutonium-core implosion assembly, Mk-VII pattern. Arms on redstone input, fuses for 3 s, then initiates. Field-rated yield. Recommended minimum standoff: the next biome over. (Fat Man wishes it had this trigger logic.)
